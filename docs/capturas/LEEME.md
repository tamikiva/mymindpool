# Capturas de las pantallas (hitos 2 y 3)

Generadas por `npm run ui-check` en Chromium (390 px y 1200 px) con **datos simulados** (usuaria ficticia «Ana»): una API falsa responde en lugar de Supabase. Sirven para ver la interfaz; **no** validan nada contra Supabase real.

- `1-equilibrio.png` — **Mi equilibrio (celular, 390 px)** con el cerebro 3D; `1b-equilibrio-escritorio.png` es la versión de escritorio. Datos que replican la referencia (Salud sugerida, «Ya avanzaste en Trabajo»)
- `2-tareas.png`, `3-tareas-despues.png` — lista con filtros, búsqueda y completar
- `4-editar.png` — edición de una tarea (muestra el error de fecha inválida)
- `5-area.png` — pantalla de Área
- `6-tareas-desktop.png` — Tareas en computadora
- `7-cerebro-2-areas-*.png`, `7-cerebro-8-areas-*.png` — el cerebro 3D con 2 y con 8 áreas (con un nombre de 40 caracteres, que en el dibujo se acorta con «…»; el nombre completo está en la leyenda y en la lista); `7-sin-webgl.png` — la vista simplificada cuando no hay WebGL
- `8`–`13` — Rutinas: lista vacía, editor con plantilla sugerida, lista, ejecución de un paso, secuencia completa y cierre
- `14`–`17` — Mi día: pregunta de áreas, edición con aviso de tiempo, plan y cierre
- `18`–`20` — Tareas repetidas: editor, lista y repeticiones dentro de Tareas
